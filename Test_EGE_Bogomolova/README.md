# Интерактивный тест по информатике

## Файлы
- `index.html` — структура страницы и задания.
- `style.css` — оформление, состояния наведения/фокуса/нажатия.
- `script.js` — проверка ответов, массивы, циклы, DOM, события и мини-игра.

## Запуск
Откройте `index.html` в браузере. Установка дополнительных программ не требуется.

## Важное исправление в условии
В условии указано уменьшение на 480 бит при переходе с 16-битной кодировки на 8-битную.
Разница составляет 8 бит на символ: 480 / (16 - 8) = 60 символов.
Поэтому правильный числовой ответ — **60**, а не 30, как ошибочно указано в исходном промпте.
